# Discus asset handoff for level creation

**Status:** prototype asset and in-place swim animation, tested in a cooked desktop review scene. This is not a complete tank or player controller. Independent fin strokes and steering have not been implemented. The level creator should integrate and test them as needed using existing engine facilities; engine code changes require Will’s explicit permission.

## Build and select a texture

From the repository root, using the existing Blender and World Foundry level-build tools:

```sh
python3 wflevels/discus_asset/texture.py
DISCUS_PALETTE=wild-brown blender --background --python-exit-code 1 --python wflevels/discus_asset/model.py
blender --background --python-exit-code 1 --python wflevels/discus_asset/export_level.py
bash wftools/wf_blender/build_level_binary.sh discus_asset
python3 wflevels/discus_asset/check_desktop.py
```

Replace `wild-brown` with a name in `palettes.json`. The output is a **review scene**, and the export currently scales the 0.2 m source mesh by ten. Adapt the texture path, actor setup, script and scale to the destination level rather than assuming its actor indexes or runtime settings. The texture is 1024 × 1024; this review uses 2048 × 2048 textile pages and matching desktop VRAM slots. Confirm the destination host’s actual page and slot configuration and inspect its cooked engine output. Blender’s preview uses a V flip while exported UVs use the World Foundry top-origin convention.

## Integration and known limitations

- Model axes: **+X toward the nose, +Z up**. Paired fins are part of the same mesh. The current `swim.fth` applies a common body/tail wave; its separate fin-wave amplitude is zero because the photographic UVs do not encode fin root-to-tip weights.
- A level needs its own movement, steering, camera, bounds, actor ownership and input design. Independent fin strokes and fin-root attachment through turns remain future work. The source photo contains a pectoral fin baked into the flank.
- The photographic textures still contain background near some fin edges. Inspect the chosen pattern, both sides, close views and motion before treating it as final art. The spotted source includes broken lines as well as spots; the turquoise-pattern image is a leopard photograph and is not verified as a named turquoise strain.
- The twelve brown variants are **creative colorways**, not twelve identified biological strains. Palette-only invariance applies within that family; the spotted and turquoise-pattern images change the pattern.
- Desktop captures establish that the review scene rendered; they do not establish target-device performance, controller behavior, independent-fin motion or final integration quality. Use the shared Chromecast coordinator for any applicable device tests.
- The [discus modelling guide](../../docs/plans/discus-reference/discus-modelling-guide.svg) contains estimated construction dimensions, not measured front-view specimen proportions.
