# Discus asset

The editable source is `discus.blend`, generated by `model.py`. Coordinates are metres, +X nose and +Z up. The mesh has 1,451 source vertices; dorsal, anal, tail and paired fins are part of one mesh. The material has top-origin World Foundry UVs and a preview-only V flip for Blender. The design is based on the [discus modelling guide](../../docs/plans/discus-reference/discus-modelling-guide.svg); the front thickness is an estimate.

Run the following from the repository root:

```sh
python3 wflevels/discus_asset/texture.py
blender --background --python-exit-code 1 --python wflevels/discus_asset/model.py
blender --background --python-exit-code 1 --python wflevels/discus_asset/export_level.py
bash wftools/wf_blender/build_level_binary.sh discus_asset
python3 wflevels/discus_asset/check_desktop.py
```

Set `DISCUS_PALETTE` to a name in `palettes.json` for the Blender model step and rebuild the export and cooked scene to select a different texture; the default is `wild-brown`. The twelve brown-family 1024×1024 indexed PNGs use identical pixel indices and differ only in palette; matching RGB TGA files are generated for textile. The standalone review scene uses 2048×2048 texture slots; the desktop checker supplies the matching VRAM options.

`engine.png` is a desktop World Foundry capture of the cooked turquoise scene. The revised mesh overlaps the tail and fin roots to eliminate the visible gaps found in the first capture. The pattern families have been captured on desktop. `swim.fth` uses the existing `swim-deform` primitive to apply a continuous body-and-tail wave to the whole mesh in the review scene. The fin-wave channel is zero because the photographic UVs are not fin root-to-tip weights. The fish stays in place; independent pectoral/dorsal fin strokes, steering and device performance are not yet implemented or verified. The review scene is not an aquarium level.

The current texture is derived from [Brown Discus Symphysodon aequifasciatus](https://commons.wikimedia.org/wiki/File:Brown_Discus_Symphysodon_aequifasciatus.jpg), photograph by Brian Gratwicke, licensed [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). The image is cropped, resized, quantized and recolored. The generated `texture-photo-v1.png` and all palette variants are adaptations of that photograph. The earlier AI-generated `texture-source-v2.png` is retained as an unused alternative. `texture.py` quantizes the photo once and changes palette entries only. The unrotated `wild-brown` palette is the photograph’s original color. The default was recooked and captured on desktop. Some background remains around fin edges and the photographed pectoral fin is baked into the flank; these are visible limitations of the prototype.

## Pattern families and image credits

The brown-pattern colorways are modest palette changes to the same indexed photograph, not names of biological strains. `wild-brown` is the original photographic palette. Different pattern families are separately derived images; no claim is made that their pixel indices match the brown family.

- **Brown:** Brian Gratwicke, [Brown Discus Symphysodon aequifasciatus](https://commons.wikimedia.org/wiki/File:Brown_Discus_Symphysodon_aequifasciatus.jpg), [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). Cropped, resized, quantized and recolored.
- **Turquoise-pattern:** cuatrok77, [Asian Leopard Discus](https://commons.wikimedia.org/wiki/File:Asian_Leopard_Discus_(Symphysodon).jpg), [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/). Cropped, mirrored, resized and quantized. This is a turquoise-patterned leopard photograph, not a verified identification as a turquoise strain.
- **Spotted-reference:** Biotopica, criadero de peces disco, [Leopard Spotted Green](https://commons.wikimedia.org/wiki/File:Biot%C3%B3pica,_breeding_discus_fish_Leopard_Spotted_Green.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). Cropped, resized and quantized; the adapted texture is distributed under CC BY-SA 4.0. Its pattern includes spots and broken lines, not exclusively spots.

The reference photographs include aquarium background and fins; portions may appear on geometry. Their use on the model is a prototype requiring visual review and cleanup, especially along fin edges. `source-blue.jpg` is an additional CC BY 2.0 photo by Brian Gratwicke, [Blue Discus](https://commons.wikimedia.org/wiki/File:Blue_Discus_fish_Symphysodon_aequifasciatus.jpg), retained as a reference and not used in the generated maps.

`check_desktop.py` records twelve desktop engine frames and `swim.gif`; it checks for pixel changes in the fish region, excluding the FPS display. The review scene is x10 scale and the wave span in `swim.fth` uses that scale. No engine source changes are needed.

## In the repository, and the Discus tank

Committed 2026‑11‑22 with the Aquarium's Discus tank ([plan](../../docs/plans/2026-11-22-discus-tank.md)). In git: the generators (`model.py`, `texture.py`, `export_level.py`, `check_desktop.py`, `preview.py`, `render_palettes.py`), `palettes.json`, `swim.fth`, `discus.blend`, the review scene's `textile.flags`, the brown source photograph (`brian-gratwicke-source.jpg`) and the default colourway as an indexed PNG (`wild-brown.png`; its RGB pixels equal `wild-brown.tga`). Everything else regenerates: `texture.py` writes the other colourways, the TGA files and `master-index.png`, and the review scene's cooked files come from the build commands above. The two other pattern families' photographs (`source-spotted-green.jpg`, `source-spotted.jpg`) are not committed; fetch them from the Commons pages credited above before running `texture.py`, which stops when they are missing (after writing the twelve brown colourways).

The mesh is in `discus_geometry.py`, moved out of `model.py` unchanged so that the tank's species module, `wflevels/aquarium/discus_school.py`, builds the same vertices, faces and UVs. The tank ships `wild-brown` only, resampled to 512 × 512.
