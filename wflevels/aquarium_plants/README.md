# Planted Tank

One sea urchin among eight runtime plant groups. The current urchin has a textured rounded test, 61 primary spines and 40 smaller spines, plus eight pale tube feet. Body and feet share a deterministic 256 × 256 atlas in the permanent asset slot; the plant texture page stays unchanged. Feet use the existing material-opacity capability. Phase 3 has 3,540 animal source triangles, 17 animal actors and 46 scene actors. Eight primary spines are detached from the body into rigid actors with basal origins; their triangles are removed from the body to avoid duplication. All eight reuse the existing shared atlas.

Build: `bash wflevels/aquarium_plants/build.sh`. Run: `bash wflevels/aquarium_plants/run.sh`. D-pad directions crawl directly on the substrate at 0.0125 world units/second, with normalized diagonals. Tap A changes wide/close view; hold A opens plant settings. The back arrow applies/closes settings, returns from the level to the selector, and exits from the selector. Plant growth speed does not control the animal.

Menu index 5 is **Planted Tank** in `aquarium-menu.manifest`. The existing freshwater/saltwater settings remain available; the urchin realism preview uses saltwater. A suitable freshwater resident or a plant-only freshwater view remains a separate design decision.

Content checks: `pytest -q tests/test_aquarium_plants.py tests/test_urchin_asset.py tests/test_urchin_motion.py tests/test_urchin_spines.py`. Desktop debug-bridge traces check visual/control correctness only; performance comparisons use matched Chromecast jobs through the coordinator. See [the sea-urchin plan](../../docs/plans/2026-10-05-sea-urchin-realism.md) and [phase comparison](../../docs/plans/2026-10-05-sea-urchin-realism/comparison.md).

The source model and atlas generator live in `wflevels/aquarium_tanks/urchin.py`; runtime plant authoring remains independent. Phase 2 uses world-space adhesive contact anchors, release/recover/reach envelopes and actual Euclidean body travel. Stems aim at body roots through existing rotation/scale mailboxes; discs tilt with these rigid prototype stems. The Director owns all eight contact slots (840–967), with scratch at 800–839; feet have no individual behavior scripts. Phase 3 adds eight representative basal spine pivots without engine edits, also driven by the Director. They move through smooth, bounded move/hold/recover envelopes with different wait times and modest actual-travel orientation bias. Spine slots are 1000–1095 (12 cells each), scratch 1100–1111. Other spines stay static. The sea-anemone/generic-deformation work remains set aside.

Phases 0–3 are measured on Chromecast 1. Phase 3 release median: 13.514 FPS (−0.91% vs anchored-contact phase 2); single instrumented repeat observed +0.170 ms actor CPU, +0.222 ms Director CPU and +0.467 ms render CPU vs phase 2. Three release repeats per phase; CPU deltas are exploratory single-run observations. Normal gameplay preserves original runtime arguments and plant growth; fixed mature seed 713 is used only by benchmark APKs. All eight normal-gameplay selector/back-arrow/Home/resume checks passed.
