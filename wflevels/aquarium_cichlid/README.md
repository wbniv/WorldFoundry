# Cichlid asset draft

Run `python3 wflevels/aquarium_cichlid/build.py` (Pillow, NumPy and ReportLab), then `blender --background --python-exit-code 1 --python wflevels/aquarium_cichlid/make_blend.py`. The generated `cichlid.blend` and OBJ are editable source assets; +X is the nose, Z is up, and the source spans 0.96 units in length. The OBJ is not a cooked World Foundry mesh. The 642 vertices and 1,252 triangulated faces include double-sided fins.

`master-index.png` is the 256×256 indexed source. `palettes.json` maps its eight indices to sRGB values; the twelve indexed PNGs have exactly the same index bytes, so only their palettes differ. The contact sheet and three views are software previews, not engine captures. The PDF poster is generated by `build.py`; use `pdftoppm -f 1 -singlefile -scale-to 1800 -png docs/reference/cichlid-poster/cichlid-a3.pdf docs/reference/cichlid-poster/poster` to regenerate its preview.

This is an initial art draft. It has no animation or World Foundry cooked export yet. The World Foundry top-origin UV convention, texture cooking and page configuration need validation in a real engine capture. The Blender material uses ordinary OBJ UVs and has not been prepared for the engine exporter. No Chromecast performance or gameplay has been verified.
