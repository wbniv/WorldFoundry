# Bomberman multiplayer prototype

Status: unfinished two-player draft, saved for review. This is not the completed Cat-Boom! Internet multiplayer implementation.

The draft uses the existing room transport and includes a basic server simulation and controller/receiver views. It predates the agreed two-to-four-player scope, smooth movement, sequenced inputs, prediction/reconciliation and capacity qualification. The shared platform regression tests pass; they do not establish gameplay correctness or acceptance for this draft.

Follow the [review plan](../../../docs/plans/2026-10-04-bomberman-online-multiplayer.md) and [AWS/Cloudflare capacity plan](../../../docs/plans/2026-10-04-bomberman-aws-room-capacity.md) when implementation resumes. Committing the prototype does not resume implementation or deploy it.
