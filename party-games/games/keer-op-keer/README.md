# Keer op Keer

Project directory for a new game based on Keer op Keer, also published as
**Encore!** in English and **Noch mal!** in German. This directory currently
contains the base-game rules archive; implementation has not started.

See the [Chromecast implementation plan](implementation-plan.md), a phased
draft awaiting review before implementation.

## Archived instructions

Start with [the official English rulebook](rules/encore-official-rules-en.pdf).
An existing publisher English edition was found, so no new translation was
needed. It includes multiplayer rules, scoring, examples, and solo play.

A [plain-text transcription](rules/encore-official-rules-en.txt) is also
available. It includes all six pages, with Unicode dice faces and color
symbols; refer to the PDF for board illustrations.

| File | Language | Source |
| --- | --- | --- |
| [Encore official rules](rules/encore-official-rules-en.pdf) | English | [Schmidt Spiele publisher PDF](https://www.schmidtspiele.de/files/Retail/72dpi_PNG/88252_Encore_GB.pdf) |
| [Keer op Keer rules](rules/keer-op-keer-rules-nl.pdf) | Dutch | [999 Games rulebook scan hosted by The Game Room](https://www.thegameroom.org/wp-content/uploads/2024/04/Spelregels_Keer_op_Keer-1.pdf) |

Both PDFs contain six pages. The Dutch PDF is an image scan. Files were
downloaded unchanged and checked as PDFs on 2026-10-04; the English text was
extracted successfully and the Dutch cover was visually checked.

These references cover the original base game. Sequels and Deluxe variants
are outside this archive.
