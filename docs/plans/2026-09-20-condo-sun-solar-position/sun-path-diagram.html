The swing (27°→77°→32°→ 10° altitude; 84°→277° azimuth across the day) is the dynamic range CONDO_SUN_DATETIME introduces once wired up, replacing the single fixed 50°/150° pair.
Mechanism: a small self-contained NOAA-style solar-position function (pure Python, stdlib math + zoneinfo only — no new pip dependency, so it runs identically inside Blender's bundled interpreter and plain python3) computes (altitude, azimuth) from SITE_LATLON + a resolved local datetime, replacing the two hardcoded SUN_ALT_DEG/SUN_AZ_DEG literals in site_constants.py. Default datetime = the actual wall-clock moment the script runs (per your direction); CONDO_SUN_DATETIME (ISO 8601 local) pins a fixed moment for a reproducible/CI rebuild. Both downstream consumers (blender_create_condo.py's Sun actor and make_site_textures.py's painted sun disc) already read through sun_compass(), so neither needs to change.
