# Advent calendar: Tom of Finland-inspired concept handoff

Create a high-fidelity, widescreen visual concept for another world in the [Advent Calendar plan](../2026-11-21-advent-calendar.md). The user requested a Tom of Finland-inspired style: bold, confident mid-century figure drawing, detailed graphite and ink shading, and playful queer joy. The original request did not specify clothing or explicit content.

Place adult men in a festive winter city scene. Integrate 24 readable numbered doors or windows into the setting, with a few open to show miniature festive surprises. The scene should fill a television screen and feel like artwork rather than a UI panel. Use original characters and composition. The image is a concept, not a running build; the shared plan defines calendar dates, interaction and the actual 24 surprises.

A previous built-in image-generation attempt requested a fully clothed interpretation with leather jackets, boots, scarves and caps. The image generation service rejected that prompt with a safety-system error; no image was generated. The later request for a more explicitly fetish-focused variant is separate from this original brief.

Save any successful concept in this directory, add it to the plan and its browser version, and record the result accurately. Follow the other agent's applicable policies and tool constraints.
