How it works

  • Each panel seats against a stop on the frame's outer edge and is latched from inside; it can only leave inward.
  • All six panels are identical, so any one fits any bay.
  • Black pet mesh stops pigeons, cats and mosquitoes. It cuts rain spray but does not stop wind-driven rain.
  • Optional: clear polycarbonate inserts of the same size for the wet season.
