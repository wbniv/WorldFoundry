Level memory settings

An author chooses the level's load-time values once. The build validates them and writes the values used by existing engines; Settings shows an informational view.

How the values travel

The RAM chunk is the runtime authority. This first implementation does not resize memory while a level is running.

1. AuthorSet object heap, asset sizes, room slots, and load-time behavior in the level configuration.
→ 2. Validate and buildReject invalid ranges and overflow; use one configuration snapshot for both outputs.
→ 3. Load and inspectRAM fields configure the allocators. A read-only catalog displays the authored values.
