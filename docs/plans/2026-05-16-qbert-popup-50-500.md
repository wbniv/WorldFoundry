# Plan — +50 and +500 floating popup labels

**Date:** 2026-05-16
**Status:** Complete

## Problem

Two score popup labels were missing from the Q✱bert popup system:

- **+50** — the 2nd cube hop in L2/L4 (two-step cube cycles) was calling
  `_popup_trigger_forth(25)` instead of `_popup_trigger_forth(50)`, so the
  wrong gold "+25" label appeared instead of an orange "+50".
- **+500** — Coily falling off a disc awarded 500 points but had no popup
  trigger at all; `POPUP_VALUE_MB` was never set in either retirement block.

## Changes

All in `wflevels/qbert_practice/blender_create_qbert.py`:

1. **Two new popup actors** — `_make_popup_actor('50', '+50', (1.00, 0.55, 0.00))`
   (orange) and `_make_popup_actor('500', '+500', (1.00, 0.20, 0.80))` (hot magenta),
   with actor indices `POPUP50_ACTOR_IDX` and `POPUP500_ACTOR_IDX`.
2. **Fix +50 trigger** — changed `_popup_trigger_forth(25)` → `_popup_trigger_forth(50)`
   in the two-step cube hop handler (the `dup 1 = if` branch).
3. **Coily retirement** — inserted `INDEXOF_X/Y/Z_POS` capture into
   `POPUP_PENDING_X/Y/Z_MB` and `500 → POPUP_VALUE_MB` in both disc retirement
   blocks (col=-1 and col=2), **before** the `REDBALL_PARK_Z 3011 write-mailbox`
   park line so the snake's pre-park world position is captured.
4. **Director dispatch chain** — extended the popup-tick if-else-then chain from
   3 arms (300/100/25) to 5 arms (500/300/100/50/25), updated `then` count from
   `then then` to `then then then then`, and extended both the park-on-trigger
   and countdown-park blocks to include the two new actors.
5. **cbRoom pool** — bumped from 1,500,000 → 1,800,000 in
   `qbert_practice-standalone.iff.txt` to accommodate the two new 3D text mesh
   actors (~325 KB combined room usage).
