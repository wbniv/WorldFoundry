1. Open from the TV launcher. No clock is named, so the engine's own level menu shows, built from a manifest: a title, a prompt and one line per clock. Back returns to it.
2. Start as a screensaver. The Dream is told which clock to play (its saved choice, or Random resolved once), so the menu never appears. am start … --es clock tide_harbour does the same from a shell or the coordinator.

3. Choose it once. The same shell-only settings provider the Aquarium and Seahorse Dreams use offers the choice (clock:random, clock:minute_machine, clock:tide_harbour), so the coordinator and the KDE tray can set it too.
The bundle is one cd.iff: the clock levels in table-of-contents order, plus the menu chunk after the last. A level added later is one manifest line and one entry in the app's list of clocks.
