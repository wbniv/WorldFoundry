## Scope

Phase A of the KDE theme (per the investigation at
[`docs/investigations/2026-05-24-kde-themes.md`](https://github.com/wbniv/foundrylinux.org/blob/master/docs/investigations/2026-05-24-kde-themes.md)
in foundrylinux.org):

1. **3 wallpapers** — KDE-format (`metadata.json` + multi-resolution images), one active
   default. All generated programmatically from a Python script; no external assets required.
2. **`FoundryLinux.colors`** — KDE color scheme INI. Already in the package at
   `data/color-schemes/FoundryLinux.colors`; reviewed and finalized here.

Everything else (Plasma Style, Aurorae, Kvantum, GTK theme, Look-and-Feel wrapper) is
deferred to Phases B–D.

## Wallpaper Designs

Three designs using `wflogo.png`, all 1920×1080 + 3840×2160 upscale + 400×225 thumbnail.

### 1. Iron Mark (`FoundryLinux-IronMark`)

Warm near-black surface (`#1a1714`). The WF logo large in the lower-right corner,
rendered as a recessed dark-monochrome manufacturer's stamp (~22% opacity), dark pixels
mapping to the raised surface colour (`#241f1b`) and light pixels disappearing into the
background. A faint red radial glow (`#f80000` → transparent) radiates from behind the
logo as if the iron hasn't fully cooled.

### 2. Red Foundry (`FoundryLinux-RedFoundry`)

The WF logo centred at full opacity. Its own red (`#f80000`) bleeds outward as a radial
gradient fading to `#1a1714` at the screen corners — the logo is the heat source for the
whole image. No other decoration; the logo does all the work.

### 3. Globe Field (`FoundryLinux-GlobeField`)

The WF logo scaled to ~92% of screen height and composited at ~12% opacity (centred
slightly right) as a background ghost texture. A red Forge-Horizon line (`#f80000` +
bloom) cuts across at 55% from top. A small crisp instance of the logo (18% screen
height) anchors the lower-left corner.

## File Layout

All files live in this repository (`WorldFoundry-wbniv`):

```
kde-theme/
├── scripts/
│   └── gen-wallpapers.py                    ← generation script (run to rebuild)
└── wallpapers/
    ├── FoundryLinux-IronMark/
    │   ├── metadata.json
    │   └── contents/
    │       ├── images/
    │       │   ├── 1920x1080.png
    │       │   └── 3840x2160.png
    │       └── screenshot.png               ← 400×225 thumbnail
    ├── FoundryLinux-RedFoundry/             ← same structure
    └── FoundryLinux-GlobeField/             ← same structure
```

For packaging, these tree into
`/usr/share/wallpapers/` via `debian/install` in the `foundry-kde-theme` package
(in foundrylinux.org, handled separately).
