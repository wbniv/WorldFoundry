# Widen the Editor Bridge to Use the Generated Map

## Context

The editor bridge (`engine/wf_edit/engine_bridge.cc`) has a hand-written `nameToPath()` table that maps OAD field names (as they appear in `.lev`/Doc) to wfmut paths (`"block.member"`). It currently covers 14 fields — the ones that were obviously useful and wired manually during M3.

Meanwhile, M3 also generated `engine/mutation/kpropmap_generated.inc`, which auto-generates wfmut's `kPropMap` from the OAD `.ht` structs and now covers **77 fields** across common, movebloc, and mesh blocks.

The result: ~63 fields that wfmut can write (e.g. `RunningDeceleration`, `StunThreshold`, `TurnRate`, all emitter/particle mesh fields) silently fall through as `NoOp` in the bridge — the panel accepts an edit, the Doc updates, but nothing reaches the viewport.

This task generates the bridge's companion map (`name_to_path_generated.inc`) from the same `.inc` OAS source files, replaces the 14 hand-written entries, and expands live-preview coverage to all 77 kpropmap fields.

## Implementation

### Step 1 — Extend `regen-headers.sh` with a new awk pass

Add a section after the kpropmap generation block that produces `engine/wf_edit/name_to_path_generated.inc`.

**Source to parse**: `common.inc`, `movebloc.inc`, `mesh.inc`  
**Rule**: for each `TYPEENTRYFIXED32|INT32|BOOLEAN|COLOR|FILENAME|OBJREFERENCE|XDATA_CONVERT(name, ...)` line:
- OAD name = first arg (trim whitespace)
- struct member = OAD name with spaces removed (`gsub(/ /,"",member)`)
- is_float = `TYPEENTRYFIXED32` → `true`, all others → `false`
- block prefix = which `.inc` file (`common`, `movebloc`, or `mesh`)
- emit: `{"OAD Name", {"block.member", is_float}},`

Skip `TYPEENTRYXDATA_NOTES` (no field-name arg) and structural macros (`GROUP_START`, `PROPERTY_SHEET_*`).

**Output path** (special-cased like kpropmap, to write into the source tree):

```bash
if [ "$OUTDIR" = "$SCRIPT_DIR" ]; then
    NAMETOPATH_INC="$SCRIPT_DIR/../../../engine/wf_edit/name_to_path_generated.inc"
else
    NAMETOPATH_INC="$OUTDIR/name_to_path_generated.inc"
fi
```

**Generated file header**:
```cpp
// name_to_path_generated.inc — auto-generated by regen-headers.sh. DO NOT EDIT.
// Regenerate: task gen-oas-headers
```

The awk one-liner (model after GEN_FIELDS already in the script):

```awk
GEN_NAMEPATH='
/TYPEENTRY(FIXED32|INT32|BOOLEAN|COLOR|FILENAME|OBJREFERENCE|XDATA_CONVERT)\(/ {
    match($0, /TYPEENTRY[A-Z_]+\(([^,)]+)/, arr)
    oad = arr[1]; gsub(/^[ \t]+|[ \t]+$/, "", oad)
    member = oad; gsub(/ /, "", member)
    if (member ~ /^[A-Za-z_][A-Za-z0-9_]*$/)
        printf "{\"" oad "\", {\"" blk "." member "\", %s}},\n",
               ($0 ~ /TYPEENTRYFIXED32/) ? "true" : "false"
}'
```

Run it three times (once per `.inc`) into one output file, with a comment header per block.

### Step 2 — Replace the hand-written `nameToPath()` body in `engine_bridge.cc`

File: `engine/wf_edit/engine_bridge.cc`, lines 200–218

Replace the `static const std::unordered_map<std::string, PathInfo> m = { ... 14 entries ... };` with:

```cpp
static const std::unordered_map<std::string, PathInfo> m = {
#include "name_to_path_generated.inc"
};
```

The `PathInfo` struct and `nameToPath()` function signature are unchanged. The `#include "..."` uses the source-relative path; the file is in the same directory as `engine_bridge.cc`.

### Step 3 — Commit plan doc + regenerate + build

1. Write `docs/plans/2026-05-21-widen-editor-bridge.md` (repo plan doc, committed with the code).
2. Run `task gen-oas-headers` — produces the new `name_to_path_generated.inc`.
3. Run `task build` (Debug, the wf_edit CMake target) — must compile clean.

## Verification

**Compile-time**: `task build` with no errors or new warnings on `engine_bridge.cc`.

**Bridge dump**: Set `WF_EDIT_BRIDGE_DEBUG=1` and launch wf-edit on snowgoons. `DumpTranslations()` output should show ~79 fields mapped (77 OAD + Position + Orientation) rather than the current ~16.

**Live test**: Select the player actor, edit a previously-NoOp field ("Running Deceleration", "Stun Threshold", or a particle mesh field like "period") — confirm the bridge log shows `FieldFloat/FieldInt` (not `NoOp`) and the engine accepts the value without crashing.
